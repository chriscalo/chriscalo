Hi, I'm Chris 👋🏼

I design and code and love working in the space between the two.

Here I create tools for web and Node.js app development and prototyping.

- [Unicode Picker](https://chriscalo.github.io/unicode-picker/): a searchable
  Unicode character picker for the browser
- [dev-skills](https://chriscalo.github.io/dev-skills/): a library of
  software-development skills for AI coding agents
- [sh-cmd-tag](https://github.com/chriscalo/sh-cmd-tag): template tag for
  shell commands with streaming output, safe interpolation, and flexible I/O
- [schema-fns](https://github.com/chriscalo/schema-fns): composable schema
  functions for input transformation and validation
- [rpc-light](https://github.com/chriscalo/rpc-light): a lightweight RPC
  library for the browser and Node.js
- [file](https://github.com/chriscalo/file): a no-fuss utility for reading
  file contents in Node.js
- [vite-multipage](https://github.com/chriscalo/vite-multipage): Vite + Vue 3
  multipage app starter
- [express-fs-autorouter](https://github.com/chriscalo/express-fs-autorouter):
  file-based routing for Express
- [Bookmarklets](https://chriscalo.github.io/bookmarklets/): browser
  bookmarklet actions like copying a clean URL, grabbing the page's text, or
  snapshotting the DOM
